Learn something.
Make something.

A small independent space for experiments, useful software and practical solutions.

I come across a problem, get curious about it, learn how it works, try to make a solution, and if the result is useful, I share it.

Curiosity is
enough to start.

Passion Projects did not begin as a plan to build a big software company. It started from a simple habit: when something is difficult, repetitive or missing, I like to see whether I can make it better.

I learn from documentation, open-source projects, experiments, tutorials and AI. I am not an expert in everything I try. A project is often part of the learning process itself.

When something finally works, I put it here. If it helps someone else save time or solve the same problem, even better.

Small is
still useful.

The point is usefulness, not size. A tiny utility that removes one annoying task can be worth making.
